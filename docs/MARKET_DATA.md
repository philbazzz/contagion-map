# 시장 지표 자동 수집 — 설정 · 운영 안내

상태: **연동 코드 구현 완료 · 실제 수집 검증 미완료**
(API 키 없이 개발했고, 작업 환경에서 외부 API 접속이 막혀 있어 실제 호출은 하지 못했습니다. 모의 응답으로 변환 · 정규화 · 오류 처리를 테스트했습니다.)

## 1. 수집하는 지표

| 항목 | 하이일드 가산금리 (HY OAS) | H100 GPU 임대 매물가 |
|---|---|---|
| 쉬운 설명 | 위험도가 높은 기업들이 국채보다 더 부담하는 추가 금리 | 온라인 GPU 임대 플랫폼에 올라온 H100 매물의 1장 · 1시간 가격 |
| 출처 | FRED API, 시리즈 `BAMLH0A0HYM2` (ICE BofA US High Yield Index OAS) | Vast.ai 매물 조회 API `POST https://console.vast.ai/api/v0/bundles/` |
| 단위 | 원자료 % → **bp로 변환 (1% = 100bp)**, 변화도 bp 차이 | **USD / GPU · 시간** (매물 시간당 총액 ÷ GPU 수) |
| 수집 주기 | 12시간마다 확인 (발표는 미국 영업일 기준 하루 1회) | 하루 1회 스냅샷 (같은 날 · 같은 조건은 1건만 저장) |
| 표시 | "최신 발표값 (실시간 아님)" | "최근 수집값 (실시간 아님)" |
| 과거 이력 | FRED가 2026년 4월부터 **최근 3년치만 제공**. 받은 범위만 저장하고 없는 이력은 만들지 않음 | 과거 이력 API 없음. **수집 시작일부터 직접 축적**. 7일 · 30일 이전 값이 없으면 "이력 부족" |

### GPU 비교 조건 (기본값, `.env`의 `GPU_CONDITION_JSON`으로 변경 가능)
- 모델: `H100 SXM` (PCIe · NVL은 다른 상품이라 섞지 않음), 메모리 80GB급 이상
- 임대 유형: **온디맨드만** (`ondemand`). 중단 가능한 입찰형(`bid`)과 섞지 않음
- 매물당 GPU 1~8장 → 모두 **1장 기준으로 환산**
- 인증 호스트만, 지역 전체
- 부대비용: 최소 디스크 1GB 저장비는 포함, 네트워크 전송비는 제외
- 표시값: 중앙값, 25~75% 구간, 매물 수 (매물 수는 거래량 · 수요 · 가동률이 아님)
- 조건이 바뀌면 다른 조건 키로 저장되어 서로 비교하지 않음. 같은 조건이어도 매물 구성이 날마다 바뀌어 가격이 움직일 수 있음

### 해석 제한
- HY OAS는 미국 하이일드 채권 **지수 전체**의 가산금리입니다. CoreWeave 개별 스프레드나 부도 확률이 아닙니다.
- GPU 매물가는 한 플랫폼의 호가입니다. CoreWeave 실제 계약단가나 시장 대표가격이 아닙니다.
- 두 지표 모두 시뮬레이션 가정에 **자동으로 대입하지 않습니다**. '이 상황으로 시나리오 만들기'는 관측값을 옆에 보여 주고, 가정은 사용자가 직접 정합니다.

## 2. API 키 발급 · 설정

### FRED
1. https://fredaccount.stlouisfed.org 에서 무료 계정을 만듭니다.
2. 로그인 후 **My Account → API Keys** (https://fredaccount.stlouisfed.org/apikeys) 에서 **Request API Key**를 누르고 사용 목적을 적으면 32자리 키가 발급됩니다.

### Vast.ai
1. https://cloud.vast.ai 에서 계정을 만듭니다.
2. **Manage Keys** (https://cloud.vast.ai/manage-keys/) 에서 API 키를 만듭니다. 매물 조회만 하므로 결제 수단 등록이 필요하지 않을 수 있으나, 계정 정책은 Vast.ai 안내를 따르세요.

### 키 넣기
1. `backend/.env.example`을 복사해 같은 폴더에 `backend/.env`로 저장합니다.
2. 아래처럼 값을 채웁니다 (따옴표 없이).
   ```
   FRED_API_KEY=발급받은키
   VASTAI_API_KEY=발급받은키
   ```
3. 백엔드를 다시 시작합니다 (`start_backend.bat`).

키는 백엔드에서만 읽습니다. 프런트엔드, HTML 데모, 로그, API 응답, 배포 ZIP 어디에도 들어가지 않습니다. 오류 메시지에도 요청 주소를 넣지 않아 키가 새지 않습니다. `.env`는 `.gitignore`에 포함되어 있습니다.

## 3. 자동 수집 동작

- `start_backend.bat`(FastAPI) 실행 시 스케줄러가 함께 켜집니다. 대체 서버 `serve_simple.py`도 같은 로직으로 수집합니다.
- 시작하자마자 마지막 수집 시각을 확인하고, 갱신이 필요하면 바로 수집합니다. 이후 30분마다 다시 확인합니다.
- **프로그램이 꺼져 있는 동안에는 수집되지 않습니다.** 그 기간의 GPU 스냅샷은 비어 있게 됩니다 (HY OAS는 다음 실행 때 FRED에서 받아 채워짐).
- 중복 방지: 프로세스 안의 잠금 + SQLite 작업 잠금(만료 2분), 관측값 `(시리즈, 날짜)` · 스냅샷 `(날짜, 조건)` 기본키.
- 호출 보호: 타임아웃 15초, 서버 오류 · 타임아웃 시 최대 3회 재시도(지수 대기), 호출 한도(429)는 재시도하지 않고 표시, 실패 후 60분 동안 자동 재시도 안 함, 수동 갱신은 5분에 1회, 화면 조회 결과는 60초 캐시.
- 저장소: `backend/data/market.db` (SQLite). 관측값, 스냅샷, 수집 시각, 비교 조건, 수집 로그, 실행 기록이 들어갑니다.
- 수동 수집: 화면 상단 '시장 상황 → 지금 다시 수집', 또는 `POST /api/market/refresh`.
- 끄기: `.env`에 `MARKET_SCHEDULER=false`.

## 5. 재배포 조건과 HTML 데모

- FRED의 이 시리즈는 ICE Data Indices 자료입니다. FRED 시리즈 페이지는 ICE의 사전 서면 승인 없는 복제를 금지하고, 제3자 공개 배포에 ICE 승인이 필요하다고 안내합니다. 그래서 **공개 HTML 데모에는 HY OAS 수치를 넣지 않습니다.** 로컬 앱(내부 이용)에서만 표시됩니다.
- HTML 데모에는 `python backend/export_public_snapshot.py`로 내보낸 스냅샷만 들어가며, "저장된 스냅샷 · 자동 갱신 안 됨"과 기준일이 표시됩니다. 내보낸 뒤 `npm run build:demo`로 데모를 다시 만들면 됩니다.
- Vast.ai 매물 데이터의 공개 재배포 조건은 Vast.ai 이용약관을 확인한 뒤 공개 데모에 포함하세요.

## 6. 실행 기록과 재현

'영향 확인하기'를 누를 때마다 사건 · 출발 기업 · 관심 기업 · 가정값 · **그 시점의 시장 관측값** · 핵심 결과가 `runs` 테이블에 저장됩니다 (`GET /api/runs`). 이후 시장 값이 갱신되어도 이미 실행한 결과는 바뀌지 않습니다. 같은 입력이면 엔진이 같은 결과를 다시 계산합니다.

## 7. 상장사 주가 · 원화 환산 (v0.5, MARKET VIEW)

| 대상 | 제공처 · 엔드포인트 | 키 변수 | 기준 |
|---|---|---|---|
| 미국 상장 20종목 (CRWV, NVDA, TSM, DELL, MSFT, META, CORZ, APLD, BX, MS, JPM, GS, WFC, PNC, C, USB, BLK, CG, GECC, JEF) | Finnhub `GET https://finnhub.io/api/v1/quote?symbol=`, `/stock/profile2` (시가총액). 키는 `X-Finnhub-Token` 헤더로만 보냄 | `FINNHUB_API_KEY` | 제공처 표기 '실시간'. 앱은 15분마다 조회하므로 최대 15분 지연 |
| SK hynix 000660 | 금융위원회_주식시세정보 `GET https://apis.data.go.kr/1160100/service/GetStockSecuritiesInfoService/getStockPriceInfo` (`likeSrtnCd`, `beginBasDt`) | `DATA_GO_KR_SERVICE_KEY` | KRX 일간 종가. 다음 영업일 13시 이후 공개되며, 1년 이력을 한 번에 받음 |
| 환율 | 한국수출입은행 `GET https://oapi.koreaexim.go.kr/site/program/financial/exchangeJSON?searchdate=&data=AP01` | `KOREAEXIM_API_KEY` | 매매기준율(`deal_bas_r`). 영업일 1회 고시, `JPY(100)`은 100으로 나눔, 주말·휴일은 직전 영업일 |

### 키 발급
- **Finnhub**: https://finnhub.io 가입 → Dashboard에서 무료 키 확인. 무료 플랜은 미국 상장 종목만 지원하고, 분당 60회·초당 30회 한도가 있으며, 과거 일봉(candles)은 유료입니다.
- **공공데이터포털**: https://www.data.go.kr 에서 '금융위원회_주식시세정보' 활용신청 → 마이페이지의 일반 인증키(Decoding)를 사용합니다. 개발계정은 하루 10,000건입니다.
- **한국수출입은행**: https://www.koreaexim.go.kr Open API 메뉴에서 인증키를 신청합니다. 공공데이터포털은 구 도메인 `www.koreaexim.go.kr` API가 2026.4.30 종료 예정이라고 안내했으며, 앱은 새 도메인 `oapi.koreaexim.go.kr`을 씁니다.

### 동작 규칙
- 백엔드가 켜져 있는 동안 30분마다 수집 시점을 확인합니다. 주기는 미국 시세 15분, KRX 6시간, 환율 6시간입니다. 우측 패널의 '지금 조회'로 수동 갱신할 수 있으며, 5분에 한 번으로 제한됩니다.
- 조회에 실패하면 마지막 정상값과 그 시각을 그대로 보여 주고, 실패 사유(키 미설정·인증 실패·호출 한도·응답 오류)를 함께 표시합니다. 가격을 만들어 내지 않습니다.
- 비상장 기업은 '비상장', 무료 제공처가 지원하지 않는 거래소(TSE·XETRA·LSE·Euronext·BME)는 '미지원'으로 표시합니다.
- **원화 환산 = 현지 주가 × 같은 통화의 KRW 환율.** 한국에서 거래되는 가격이 아닙니다. 주가 기준 시각과 환율 고시일은 따로 표시합니다.
- 과거 차트의 원화 값에는 날짜별 환율을 씁니다. 환율이 없는 날은 비워 두고, 현재 환율로 채우지 않습니다. 미국 종목 차트는 앱이 수집한 날의 종가만 쌓입니다(무료 플랜 제약). SK hynix는 1년 이력을 바로 표시합니다.
- 1일(분 단위) 차트는 무료 제공처에 분봉이 없어 지원하지 않습니다.

### 재배포
- KRX 시세(공공누리 제4유형)는 제3자 제공·재배포가 금지됩니다. Finnhub 무료 데이터도 개인 이용 조건입니다. 그래서 **공개 HTML 데모에는 주가·환율을 넣지 않습니다.** 데모의 MARKET VIEW는 '공개 데모에는 시세 미포함'으로 표시합니다.

## 8. GitHub Pages — 공개 재배포와 주식 수치 시세

### 확인한 제한
| 제공처 | Pages에 수치 JSON 재배포 | 근거 |
|---|---|---|
| Yahoo Finance / yfinance | **불가** (확인된 재배포 권리 없음) | 비공식 스크래핑 · ToS상 재배포 비허가로 취급 |
| Finnhub 무료 | **불가** | 개인/앱 이용 중심, 공개 정적 파일로의 대량 재배포에 부적합 |
| KRX / 금융위원회 | **불가** | 공공누리 제4유형 · 제3자 재배포 금지 |
| FRED UST yields (DGS10, DGS2) | **가능** (출처 표기) | 미국 재무부 공개 시계열 · FRED API |
| FRED HY OAS (BAMLH0A0HYM2) | **불가** | ICE Data Indices · 제3자 공개 배포에 사전 승인 필요 |
| TradingView 위젯 | **임베드만** | 위젯에서 숫자를 추출·저장하지 않음 |

### Pages에서 실제로 하는 일
1. **금리 충격·노출·행성 상호작용** → 전부 브라우저 TS 엔진 (백엔드 불필요).
2. **국채 관측값** → Actions가 `scripts/fetch_fred_public.py`로 `market.json` 갱신 (`FRED_API_KEY`는 Actions Secrets만).
3. **주식 수치 표** → `quotes.json`에 티커·거래소·`not_redistributable` 상태만. 숫자는 넣지 않음.
4. **종목 시세 UI** → 상세 패널 TradingView (기존 유지).

### 실무 대안 (주식 수치를 Pages에 넣고 싶을 때)
가장 작은 호환 백엔드: Cloudflare Worker / 작은 Vercel 함수가 **라이선스된** 벤더(예: Polygon delayed, Twelve Data 등 **재배포·공개 표시가 계약에 명시된** 플랜)에서 받아 JSON을 반환. API 키는 서버 시크릿만.  
무료·키리스·재배포 가능 제공처를 확인하기 전에는 수치 시세를 정적 파일에 넣지 않습니다.
